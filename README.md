# Progetto Danza Bergamo

Sito pubblico + area maestre/genitori della scuola di danza.

- **Stack**: Next.js (App Router) + TypeScript + Tailwind, Supabase, Netlify.
- **Stato**: Fase 1 completata (sito pubblico con dati di esempio).
- I dati di esempio stanno in `src/dati-esempio/dati.ts`; le pagine li leggono solo tramite `src/lib/dati.ts`.

## Avvio in locale

```bash
npm install
npm run dev
```
